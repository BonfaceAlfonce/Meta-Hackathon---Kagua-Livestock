## Project status

Everything in this project was built during the hackathon.

- React/Vite frontend with Supabase authentication and seamless switching between farms.
- Temperature, humidity, ammonia, and other telemetry displayed by zone.
- Realtime database subscriptions, private camera snapshots, alerts, and CSV export.
- Database designed to support multiple species, individual animals, GPS tracking, notification preferences, and reports.

### Competitive analysis and differentiators

- **Market gap:** No similar product currently exists in Africa.
- **Affordability:** Uses low-cost hardware, including ESP32 devices costing approximately $25.
- **Communication:** WhatsApp and SMS alerts are more accessible than email in areas with poor internet connectivity.
- **Unique data fusion:** Combines environmental telemetry with visual behavior analysis, a feature lacking in competing products.
